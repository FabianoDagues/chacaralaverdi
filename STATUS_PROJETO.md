# Status do Projeto — Horta Pedidos V3.5

## Implementado
- Empresa e logo vinculadas aos dados.
- CRUD de produtos, clientes e operadores.
- Autocadastro opcional de clientes.
- Disponibilidade diária.
- Pedido do cliente para o dia seguinte, com quantidades inteiras.
- Histórico, edição e exclusão de pedidos dentro das regras.
- Dashboard operacional e lembretes.
- Contas a receber, baixa e recibos consolidados.
- Relatórios gerenciais.
- Rotina protegida para limpeza das movimentações de teste.
- PWA/responsividade para desktop e celular.
- Menu lateral responsivo para operador e cliente.
- Impressão de romaneios restrita exclusivamente aos pedidos com entrega no dia seguinte.
